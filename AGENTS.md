# fangchunjia-web

Portfolio site for designer Chunjia Fang. React Router 8 (framework mode, SSR) on a Cloudflare Worker, content from Sanity, video from Mux, Tailwind 4, GSAP + Lenis for motion. npm, not pnpm.

## Verify

There is no test or lint script. Verify a change with:

- `npm run typecheck` (also regenerates Cloudflare and route types; run it after adding or renaming a route).
- `npm run build`.
- For UI changes, run `npm run dev` (http://localhost:5173) and look at the page. Typecheck and build pass without proving the motion works.

Typecheck currently has a known error at `app/routes/_layout._index.tsx` (`home.grid` possibly undefined). Treat it as pre-existing until it is fixed.

## Layout

- Routes are file-based (`flatRoutes()`). `_layout.tsx` is the shared shell: Lenis smooth scroll, Header, Flirt, Quote, ProgressBar. Pages render into its `<Outlet />`.
- GROQ queries live in `app/lib/queries.ts`. `app/types/sanity.types.ts` is generated by Sanity TypeGen and the schema lives outside this repo; regenerate it, never hand-edit.
- Sanity project `bhisrdlp`, dataset `production`, public read, no secrets or `.env` needed.

## Conventions

- **Accent color**: `--accent` is set per project at runtime (`app/utils/applyAccentColor.tsx`). Use `text-accent` / `--accent` for fills and text, and `--accent-shadow` for the Flirt and Quote rims (it lifts dark accents so the rim stays visible).
- **Cross-component UI state** lives in nanostores (`app/stores/ui.ts`). Each atom's comment names its owner component; write to an atom only from its owner.
- **Text distortion** is a static SVG `feTurbulence` -> `feDisplacementMap` filter. Tune the look only in `app/lib/distortPresets.ts`. Render text through `<DistortedText>` or Portable Text via `portableTextDistort.tsx`. `<DistortionDefs>` in `root.tsx` emits one shared `<filter>` per preset.
- **GSAP**: import `gsap` from `~/lib/gsap` and animate with `useGSAP` (registered in `root.tsx`, browser only).
- **Lenis**: a component that needs the Lenis instance must render inside `<ReactLenis>`, which is why `Main` is split out in `_layout.tsx`. Call `useLenisAutoResize` when content height changes after mount.
- **Mux blur-up** (`app/lib/mux.ts`) never throws: failure returns `null`, so callers must handle a missing placeholder.
- **Fonts**: ABC Otto (trial license) for Latin, FZShengSKSJW for CJK, both from `public/fonts`.

## Runtime

Server code runs on Cloudflare Workers (`nodejs_compat`). Keep it free of Node-only APIs, and treat module-level state, such as the Mux cache, as per-isolate and best-effort.

`worker-configuration.d.ts` and `build/` are gitignored. Both are regenerated by `npm install`, `npm run typecheck` and `npm run build`.
